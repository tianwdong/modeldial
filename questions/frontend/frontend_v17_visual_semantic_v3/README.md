# Frontend V17 Visual Semantic V3

This isolated candidate re-scores saved `frontend-case-stream-explorer-v17@v2`
evidence without calling a model or changing the source task, HTML, traces, or
screenshots.

The frozen score layers remain `33` behavior, `22` workflow, and `45` rule-based
visual points. Compared with visual relational v2, a correct low-area textual saving
cue can saturate the saving atom, hidden failure alerts cannot earn credit through
layout occupancy, and structure comparison operates only on `32×32` coarse geometry.

Model screenshots are holdouts. `calibration-fixtures.json` contains only hand-written
correct variants and directed mutants. Unrounded display scores remain the ranking and
audit source. `publication-manifest.json` freezes the accepted model identities,
single／median aggregation evidence, and a one-decimal public presentation; the integer
`official_score` remains only as a backward-compatible audit field.
