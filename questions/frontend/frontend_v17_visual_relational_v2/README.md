# Frontend V17 Visual Relational V2

This isolated candidate re-scores saved `frontend-case-stream-explorer-v17@v2`
evidence without calling a model or changing the source prompt, starter, HTML, traces,
or screenshots.

The frozen score contract is `33` behavior points, `22` workflow points, and `45`
rule-based screenshot points. Visual points are split across state distinction,
responsive composition, readability and hierarchy, and multi-reference structure.
Each atom keeps independently earned credit; there is no all-or-nothing gate.

`calibration-fixtures.json` contains only hand-written correct variants and directed
mutants. Model screenshots are holdouts and appear only in `regrade-manifest.json`
after the score contract was frozen.
