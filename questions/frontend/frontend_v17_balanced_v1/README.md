# Frontend V17 Balanced Progress V1

This isolated candidate re-aggregates complete, saved `frontend-case-stream-explorer-v17@v2`
score evidence. It does not change or copy the source prompt, starter, browser scorer, traces,
screenshots, or render environment.

The frozen contract is `33` behavior points, `22` workflow points, and `45` per-state squared
screenshot-progress points. Both the raw evidence score and the monotonic display score are kept.
There is no all-or-nothing workflow gate.

`calibration-manifest.json` points to existing score evidence and explicitly forbids model reruns.
`live-profile.json` permits only the pre-registered Opus replication sequence.
