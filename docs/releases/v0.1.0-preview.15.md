# ModelDial v0.1.0-preview.15

`preview.15` 修复自动来源选择和历史切换收益展示。本次发布对应 `0.1.0（Build 114）`，精确源码提交为 `82470dd02b06107a1d2d7059b78a5669d4cb93d7`。

## 本次修复

- 自动识别当前模型时，不再沿用该配置中已经过期的“本机实测”来源；自动模式只采用有效结果，并优先展示可信官方 Radar。
- 用户仍可主动选择“本机实测”浏览历史结果；已过期结果会明确标记，不再伪装成当前有效推荐依据。
- 数据来源选择在当前浏览会话内保持稳定，不会随着自动识别到的当前模型变化而静默跳转。
- 对比页恢复“历史实际切换累计”的等待时间和参考费用变化；该历史汇总与当前正在浏览的两两对比组合相互独立。

## 安装边界

这是 Apple Silicon 的 unsigned／unnotarized 预览版，没有 Developer ID 签名或 Apple notarization。手动安装 DMG 时，如 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性 → 仍要打开”；不要关闭 Gatekeeper，也无需自行运行 `xattr` 或 `spctl`。

Homebrew Cask 会明确地仅移除所安装 `modeldial.app` 的 quarantine 属性，不修改系统级安全设置。
