# ModelDial v0.1.0-preview.9

> **已由 `v0.1.0-preview.11` 取代。请勿把本版作为当前安装入口。**

> **UNSIGNED / UNNOTARIZED PREVIEW**
>
> 该预览包没有 Developer ID 签名，也未经过 Apple notarization。若 macOS 阻止首次打开，请使用“系统设置 → 隐私与安全性 → 仍要打开”，不要关闭或绕过 Gatekeeper。

这是当前 Apple Silicon 预览版，对应 `0.1.0（Build 108）`，精确源码提交为 `abf28096ccc30fb923213e257eb131a069b79633`。

## 本版变化

- 修复对比页“切换后的实际变化”漏算和长期不增长：按真实生效配置维护独立 `actual_switch` 时段。
- 支持轮询间切换回溯、复用会话、已关闭时段的迟到记录，以及超过 100 段的已完成历史累计。
- App 空闲刷新会先观察本机使用记录，再读取完整权威快照；观察失败时继续显示已保存状态并给出提示。
- 相同模型与档位的近期记录使用 Provider 消歧；无法唯一确认时继续 fail closed。

## 下载与安装

1. 下载并打开 [`modeldial-0.1.0-preview.9-macos-arm64.dmg`](https://github.com/tianwdong/modeldial/releases/download/v0.1.0-preview.9/modeldial-0.1.0-preview.9-macos-arm64.dmg)。
2. 把 `modeldial.app` 拖到 `Applications`，推出 DMG 后从 `Applications` 启动。
3. `preview.7` 及更高版本也可以进入“设置 → 软件更新”升级；`preview.6` 及更早版本仍需先手动安装新版一次。
