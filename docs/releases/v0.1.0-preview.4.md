## 本次修复

- 将官方 Radar 单次 HTTP 请求的默认超时从 3 秒提高到 8 秒，覆盖 `index.json` 和快照归档请求，降低官方端点短时首字节延迟造成的冷启动回退。
- App 刷新失败后的首次自动重试从 5 分钟提前到 30 秒；连续失败仍按 5 分钟、15 分钟、1 小时和 6 小时退避，避免高频请求。
- 刷新继续在后台执行并优先展示最近的有效缓存或内置快照；本次不加入 HTTP 层即时重试，也不改变第一方快照的 HTTPS 与 provenance 信任门禁。
- marketing version 保持 `0.1.0`，build number 升级为 `103`；预览打包默认 label 升级为 `preview.4`，并拒绝覆盖已经公开的 `preview.1`、`preview.2` 与 `preview.3`。
