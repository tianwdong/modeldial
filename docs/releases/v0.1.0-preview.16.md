# ModelDial v0.1.0-preview.16

`preview.16` 让价格目录可以独立于 App 更新，并补齐近期模型价格与自定义 endpoint 兼容性。本次发布对应 `0.1.0（Build 115）`，精确源码提交为 `1cba503bafad722e77a994c4d5341135f54d97ba`。

## 用户可见变化

- App 的价格目录改为第一方内容寻址目录。后续仅更新价格时，不再要求重新构建 App；每次运行仍冻结实际使用的目录版本，历史费用不会被新价格回写。
- 新增 `qwen3.8-flash` 官方价格：每百万输入／输出 Token 为 `$0.16／$0.47`；官方未公布缓存折扣，因此缓存输入按普通输入价估算。
- 更新近期模型价格和官网覆盖规则，支持固定官网价、周期时段价、限时促销价及超长上下文分档。
- 自定义 endpoint 的长响应改为完整流式读取，统一十进制 `128000` 输出预算，并兼容 Cloudflare 安全层的 `User-Agent` 检查；Anthropic 流式协议异常时会进行一次同题非流式回退。
- 有本机活动模型会话时，官方 Radar 推荐仍会正常显示，不再被当前会话状态遮蔽。

## 价格目录边界

- App、远端运行器和官网只读 API 消费同一份 `current.json` 与不可变 snapshot；目录更新必须同时通过 HTTPS、同源跳转、大小、schema、原始 SHA-256、语义内容哈希、provenance 和费率范围校验。
- 有效目录会保存为 last-good、不可变归档和运行级冻结副本；远端目录关闭或校验失败时回退到 last-good 或 App 内置快照。
- App 冻结包不携带维护侧抓取器或价格策略，只保留受限目录读取器和内置回退快照。

## 评测与协议能力

- 公共核心新增 HLE Deep-20 v2 的受限评分边界和 Frontend v17 独立评测核心；公开仓只保留合同、评分逻辑和合成 fixture，不包含受限题面或真实响应。
- endpoint 三种协议继续共享隐私安全的错误分类、流式事件大小上限和总响应上限；协议回退不改变模型、effort 或题目。

## 安装边界

这是 Apple Silicon 的 unsigned／unnotarized 预览版，没有 Developer ID 签名或 Apple notarization。手动安装 DMG 时，如 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性 → 仍要打开”；不要关闭 Gatekeeper，也无需自行运行 `xattr` 或 `spctl`。

Homebrew Cask 会明确地仅移除所安装 `modeldial.app` 的 quarantine 属性，不修改系统级安全设置。
