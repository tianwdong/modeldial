# ModelDial v0.1.0-preview.14

`preview.14` 修复新用户首次接入、首次扫描与结果浏览链路。本次发布对应 `0.1.0（Build 113）`，精确源码提交为 `739c9c5e55f973be59906367c222f3ae200df4b6`。

## 本次修复

- 没有本地会话时，Radar 仍按可信官方榜单给出综合推荐，并明确提示“暂无本地对比”。
- 官方榜单和已有本地扫描结果都支持自由选择两项对比，不再依赖先生成推荐决策。
- 已验证的自定义 Endpoint 在启用或切换档位后立即可从首页扫描，不再要求设置页先预扫；快速扫描在恰好启用两个档位时可直接形成计划。
- 修复首页档位计数、可关闭的模型接入提示，以及扫描预览或执行失败时没有可见提示的问题。
- 修复冻结 App 的 Endpoint worker 资源定位、TLS 初始化顺序和外部模型发现误报网络错误的问题。
- Grok Build 登录态改为明确验证，避免仅检测到 CLI 或旧配置就显示为已接入。
- 新增隔离的首启自动验收和可共享诊断日志工具，不读取真实 Keychain 值或原始会话正文。

## 验证

- 全量 Python／Swift 合同：`1467/1467` 通过。
- 首启自动验收：`PASSED`；真实模型请求、Keychain 读取和用户正式数据路径读取均为 `0`。
- 发行包：60 个 Mach-O／65 个架构记录通过 macOS 13 兼容门禁，深层 ad-hoc 签名、Designated Requirement 和 SPDX SBOM 验证通过。

## 安装边界

这是 Apple Silicon 的 unsigned／unnotarized 预览版，没有 Developer ID 签名或 Apple notarization。手动安装 DMG 时，如 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性 → 仍要打开”；不要关闭 Gatekeeper，也无需自行运行 `xattr` 或 `spctl`。

Homebrew Cask 会明确地仅移除所安装 `modeldial.app` 的 quarantine 属性，不修改系统级安全设置。
