> This is a staged, manual-install preview. It has no Apple Developer ID signature and has not been notarized by Apple. It is not the formal `v0.1.0` release, and a direct first-launch double-click is not guaranteed.

本文件是 [GitHub Release `v0.1.0-preview.1`](https://github.com/tianwdong/modeldial/releases/tag/v0.1.0-preview.1) 的版本库正文来源；Release 仍只通过受控发布流程创建和上传资产。

## 平台

- macOS 13 或更高版本
- Apple Silicon（arm64）
- Intel Mac 不支持

## 资产

- `modeldial-0.1.0-preview.1-macos-arm64.dmg`
- `modeldial-0.1.0-preview.1-build-100-macos-arm64.zip`
- `SHA256SUMS`
- `modeldial-0.1.0-preview.1-sbom.spdx.json`

DMG 内附 `UNSIGNED_PREVIEW.txt`，再次说明未签名／未公证状态和人工放行步骤。

下载后请从同一个 Release 获取 `SHA256SUMS`，在资产所在目录运行：

```bash
shasum -a 256 -c SHA256SUMS
```

校验失败时不要安装；先重新下载并确认 Release 标签为 `v0.1.0-preview.1`。

## 首次安装

1. 打开 DMG，把 `modeldial.app` 拖到 `Applications`，推出 DMG 后从 `Applications` 启动。
2. 如果 macOS 阻止首次打开，关闭提示，进入“系统设置 → 隐私与安全性”。
3. 在安全性区域找到 ModelDial 被阻止的提示，点击“仍要打开（Open Anyway）”并确认，再从 `Applications` 启动。
4. 如果没有显示“仍要打开”，重新尝试打开一次 App，再回到“隐私与安全性”查看。不同 macOS 小版本的提示文字可能略有差异。

不需要关闭 Gatekeeper。不要执行 `xattr -dr com.apple.quarantine`、`spctl --master-disable` 或其他绕过系统安全检查的命令；如果来源无法确认，请停止安装并重新核对资产和 SHA-256。

## 已知限制

- unsigned / unnotarized：没有 Developer ID、secure timestamp、Apple notarization 或 stapling。
- 当前已验证候选包构建、资产 SHA-256、DMG 只读挂载、包内签名结构和冻结后端 smoke；拖入 `Applications` 及“仍要打开”的人工放行仍需在 Gatekeeper 开启的机器上验证。这些证据不等于正式发行验收。
- 预览版不进入正式 Sparkle `appcast.xml`，也不提供 Homebrew Cask；自动更新和正式升级路径等正式签名版本完成后再启用。
- 未验证 Intel Mac、Windows 或普通用户在所有机器上的直接双击启动。
