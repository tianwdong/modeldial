## 下载与安装

1. 下载并打开 [`modeldial-0.1.0-preview.8-macos-arm64.dmg`](https://github.com/tianwdong/modeldial/releases/download/v0.1.0-preview.8/modeldial-0.1.0-preview.8-macos-arm64.dmg)。
2. 把 `modeldial.app` 拖到 `Applications`，推出 DMG 后从 `Applications` 启动。
3. `preview.7` 用户也可以直接进入“设置 → 软件更新”完成升级；`preview.6` 及更早版本需要手动安装本版一次。
