# ModelDial v0.1.0-preview.12

> **UNSIGNED / UNNOTARIZED PREVIEW**
>
> 该预览包没有 Developer ID 签名，也未经过 Apple notarization。若 macOS 阻止首次打开，请使用“系统设置 → 隐私与安全性 → 仍要打开”，不要关闭或绕过 Gatekeeper。

这是面向 macOS 13+ Apple Silicon 的 `0.1.0（Build 111）` 修复预览版。正式源码提交、资产大小与 SHA-256 将在 fresh 打包和公开回下载验证完成后补录。

## 本版变化

- 修复 `preview.11` 在正常受保护 Mac 上因 ad-hoc bundle 错误启用 hardened runtime，导致冻结 Python 后端和嵌套组件被 Library Validation 拒绝加载的问题。
- 新增逐个 Mach-O 的签名策略门禁：unsigned preview 必须全部为 ad-hoc、无 hardened runtime、无证书 Authority 和 Team ID；Developer ID 构建路径继续保留 hardened runtime 与 secure timestamp。
- 本地组件启动失败时，Radar、扫描设置和模型接入改为明确的加载／不可用状态，不再展示虚假计数、空选项或可执行操作；原始 dyld／PyInstaller 信息只在用户主动复制诊断时提供。
- Native Bridge 并行排空 stdout／stderr，并为普通操作和连接探测增加有界超时与终止流程，避免大错误输出或冻结子进程卡住界面。
- 官方 Radar 下载在单次瞬时 `unavailable` 时重试一次完整 feed；HTTPS、同源、大小、哈希和 payload 校验失败仍立即停止。

## 下载与安装

发布完成前不要继续安装 `preview.11`。`preview.12` 资产公开并验证后，可使用以下两种入口：

```bash
brew install --cask tianwdong/tap/modeldial
```

或从本 Release 下载 `modeldial-0.1.0-preview.12-macos-arm64.dmg`，拖入 `Applications` 后启动。由于本版仍未签名、未公证，首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 已知限制

- 仅支持 macOS 13+ Apple Silicon；Intel Mac 和 Windows 客户端当前不支持。
- 没有 Developer ID、secure timestamp、Apple notarization 或 stapling。
- 本机验证不能替代另一台 Gatekeeper／SIP 开启且无开发环境的 Mac 首次安装验收。
