## 下载与安装

Homebrew（个人 Tap）：

```bash
brew install --cask tianwdong/tap/modeldial
```

该 Cask 下载本 Release 的同一 DMG 并固定 SHA-256。由于当前 App 未签名、未公证，Cask 会仅对安装目标中的 `modeldial.app`（默认 `/Applications/modeldial.app`）递归移除 `com.apple.quarantine`，不使用 `sudo`，不关闭 Gatekeeper，也不修改系统级安全设置。该行为属于签名前的临时预览策略，可在 [`tianwdong/homebrew-tap`](https://github.com/tianwdong/homebrew-tap) 审查。

DMG：

1. 下载并打开 [`modeldial-0.1.0-preview.11-macos-arm64.dmg`](https://github.com/tianwdong/modeldial/releases/download/v0.1.0-preview.11/modeldial-0.1.0-preview.11-macos-arm64.dmg)。
2. 把 `modeldial.app` 拖到 `Applications`，推出 DMG 后从 `Applications` 启动。
3. `preview.7` 及更高版本也可以进入“设置 → 软件更新”升级；`preview.6` 及更早版本仍需先手动安装新版一次。
