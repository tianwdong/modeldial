## 首次安装

1. 打开 DMG，把 `modeldial.app` 拖到 `Applications`，推出 DMG 后从 `Applications` 启动。
2. 如果 macOS 阻止首次打开，关闭提示，进入“系统设置 → 隐私与安全性”。
3. 在安全性区域找到 ModelDial 被阻止的提示，点击“仍要打开（Open Anyway）”并确认，再从 `Applications` 启动。
4. 如果没有显示“仍要打开”，重新尝试打开一次 App，再回到“隐私与安全性”查看。不同 macOS 小版本的提示文字可能略有差异。

不需要关闭 Gatekeeper。不要执行 `xattr -dr com.apple.quarantine`、`spctl --master-disable` 或其他绕过系统安全检查的命令；如果来源无法确认，请停止安装并重新核对资产和 SHA-256。
