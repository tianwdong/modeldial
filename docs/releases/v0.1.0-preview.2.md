# ModelDial v0.1.0-preview.2 candidate

> **NOT RELEASED**
>
> This document describes the next unsigned / unnotarized preview candidate. No tag, GitHub Release, or downloadable `preview.2` asset exists yet.

## 目标

`preview.2` 修复 `preview.1` 的首次使用和发布配置缺口：用户应当先浏览官方 Radar，本地模型接入与本机评测是可选能力。

## 已进入源码的修复

- macOS 13+ Apple Silicon，marketing version 仍为 `0.1.0`，build number 单调递增到 `101`。
- unsigned preview 打包固定注入 `https://reference.modeldial.com/reference-snapshots`，并从 candidate 与解压后的 ZIP 回读核对。
- 没有本地 Provider 时仍保留 Radar 榜单和刷新入口；模型接入仅作为次要操作。
- 只有 snapshot kind、provenance kind 均为 `first_party_snapshot`，且 `public_official_snapshot=true` 的数据可以进入官网榜单、对比和证据展示。
- unsigned preview 明确禁用 Sparkle 更新通道；正式 appcast 和 EdDSA 公钥只允许在正式构建中成对显式配置。
- App 包写入精确 `ModelDialSourceCommit`；打包脚本要求包含未跟踪文件在内的工作树在构建前后保持干净（忽略 `.gitignore` 内容），并拒绝复用已经公开的 `preview.1` label。

## 已完成验证

- 合并定向回归 `187/187`、全量 Python `1420/1420`（`ResourceWarning` 按错误处理）和架构基线 `11/11` 通过。
- 使用官方参考快照地址、禁用更新通道完成 `./build.sh`；60 个 Mach-O／65 个架构记录通过 macOS 13 门禁，深层 ad-hoc 签名有效。
- candidate 回读为 `0.1.0（Build 101）`、arm64、官方 Radar URL 精确匹配，`SUFeedURL` 与 `SUPublicEDKey` 均为空。
- 冻结后端在隔离临时目录真实刷新官方端点成功；delivery 为 `http/refreshed`，最新快照为 15 条 `first_party_snapshot`，provenance kind 与 public official flag 均通过。

## 发布前仍需完成

- 经授权形成干净提交后运行 `build-support/package-unsigned-preview.sh`，验证 DMG、ZIP、SBOM、SHA-256、官方 Radar URL、空更新通道和源码 commit。
- 从候选 DMG 拖入 `Applications`，在 Gatekeeper 开启的 macOS 13+ Apple Silicon 机器上完成首次打开与真实 UI 验收。
- 经单独授权后才能创建 tag、GitHub prerelease 和上传资产；不得覆盖 `v0.1.0-preview.1`。

`preview.2` 仍不包含 Developer ID 签名、Apple notarization、stapling、Intel 支持或自动更新，不得作为正式 `v0.1.0` 宣传。
