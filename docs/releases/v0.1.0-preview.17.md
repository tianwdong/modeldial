# ModelDial v0.1.0-preview.17

本次维护更新修复官网榜单刷新失败与模型图标显示异常。版本为 0.1.0（Build 116），Apple Silicon、macOS 13+ 的 unsigned／unnotarized 预览版。

## 用户可见变化

- 支持官网增量更新的数据格式，不再因沿用历史成绩而整批刷新失败。
- 每个模型保留自己的评分版本与来源；不同评分口径不输出提升结论。
- 恢复官网榜单 OpenAI 等模型品牌图标，避免将运行通道误作品牌。
- 安装包排除本地题目研发依赖与缓存，保留正式题目和答案文件。

## 发布验证

正式发行候选的全量回归、冻结后端、签名、分发校验结果将在发布前补齐。原研究工作区的候选题与接口改动未纳入本次发布。

## 安装边界

本版没有 Developer ID 签名或 Apple notarization，不代表 Intel／Windows 支持。不要关闭 Gatekeeper；手动安装遇首次拦截时使用系统隐私与安全性中的“仍要打开”。
