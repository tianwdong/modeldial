# ModelDial v0.1.0-preview.17

本次维护更新修复官网榜单刷新失败与模型图标显示异常。本次发布对应 `0.1.0（Build 116）`，精确源码提交为 `7fc7722fb1c755e1f6b39684b19c0f9e4a352168`。这是Apple Silicon、macOS 13+ 的 unsigned／unnotarized 预览版。

## 用户可见变化

- 支持官网增量更新的数据格式，不再因沿用历史成绩而整批刷新失败。
- 每个模型保留自己的评分版本与来源；不同评分口径不输出提升结论。
- 恢复官网榜单 OpenAI 等模型品牌图标，避免将运行通道误作品牌。
- 安装包排除本地题目研发依赖与缓存，保留正式题目和答案文件。

## 发布验证

- 精确包体源码提交：`7fc7722fb1c755e1f6b39684b19c0f9e4a352168`。
- 隔离发行源码全量 1550 项：零失败／零错误；首次因未构建跳过的 2 项在构建后均补验通过。发行与增量快照合同 50 项通过，SBOM 实包检查通过。
- Fresh Release 构建、冻结后端、60 个 Mach-O ad-hoc 签名和 macOS 13 依赖门禁通过。
- 冻结后端回放官网 11 份快照／51 条成绩，条件刷新与不同评分身份隔离通过。
- 原研究工作区的候选题与接口改动未纳入本次发布。官网既有 Agent archive hash 断言与 Radar 体积预算失败单独保留，不以本次发布掩盖。

## 安装边界

本版没有 Developer ID 签名或 Apple notarization，不代表 Intel／Windows 支持。不要关闭 Gatekeeper；手动安装遇首次拦截时使用系统隐私与安全性中的“仍要打开”。
